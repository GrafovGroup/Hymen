Exploitant du site Web

Ce site Web est exploité par Hymen.ca Inc.

Lire les guides

Vous pouvez consulter le site sans envoyer de renseignements personnels. Il n’utilise pas de pixels publicitaires, d’analytique ou d’enregistrement de session.

Envoyer une demande de consultation

À l’envoi, le sujet, le lieu, le prénom, le courriel, le téléphone facultatif, les autorisations et la langue sont transmis à Formspree pour le compte de hymen.ca. Formspree traite la demande et envoie les notifications selon les paramètres de ce compte.

Indiquez uniquement vos coordonnées et le sujet général de votre demande. N’envoyez pas de dossier médical, de photos ou de récit intime par ce formulaire.

Vos choix

Le consentement au contact est nécessaire pour envoyer une demande. L’autorisation de messagerie vocale est distincte et facultative. Aucun consentement marketing n’est demandé. Adressez à l’équipe qui vous répond vos demandes d’arrêt de contact ou vos questions sur les renseignements transmis.

Stockage et services externes

Ce site ne conserve pas les champs dans des témoins, le stockage local ou les URL. Un envoi réussi efface le formulaire. Lorsque JavaScript est activé, les données non envoyées sont effacées lorsque vous quittez la page; votre navigateur peut proposer la saisie automatique. Les demandes envoyées sont gérées dans le compte Formspree et par ses destinataires configurés; effacer cette page ne les supprime pas.

Les liens vers les prestataires mènent à des sites indépendants ayant leurs propres pratiques de confidentialité. Ouvrir un lien ne transmet pas les renseignements du formulaire.
